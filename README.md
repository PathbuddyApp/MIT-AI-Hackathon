# MIT-AI-Hackathon
**MindWaves** is an interactive web app that generates short, engaging educational podcasts based on topics you provide. Built with Streamlit and OpenAI's GPT and TTS APIs, it creates scripts, synthesizes voiceovers, and designs unique podcast cover art—all in one click.

🔗 **Live App**: [https://mindwaves.streamlit.app/](https://mindwaves.streamlit.app/)

---

## 🚀 Features

- 🎧 **Generate Podcasts**: Enter 1–6 educational topics and receive AI-generated podcast episodes with dynamic dialogues.
- 🧠 **Smart Suggestions**: Don't know what to ask? Get intelligent topic suggestions powered by LangChain.
- 🖼️ **Custom Cover Art**: Each podcast is paired with a unique AI-generated image.
- 🔊 **Realistic Voiceovers**: Hear Alex and Sam bring your topic to life using OpenAI's TTS model.
- 🔒 **Private Scripts**: Scripts are hidden by default and viewable on demand.

---


##🛠️ Technologies Used

- [Streamlit](https://streamlit.io/) – App framework
- [OpenAI GPT-4](https://platform.openai.com/docs) – Script & suggestions
- [OpenAI TTS](https://platform.openai.com/docs/guides/text-to-speech) – Voice generation
- [DALL·E](https://platform.openai.com/docs/guides/images) – Cover image creation
- [LangChain](https://www.langchain.com/) – Topic suggestion chain
- Python

## 🛡️ Privacy

All content generation happens live in your session. No personal data is stored.
